# 每日台股研究室

本機執行的台股研究工具。**v0.9.1 提供 Windows 桌面 EXE、ChatGPT 分析、10萬元虛擬交易與開休市排程檢查。完整全市場盤中掃描與歷史回測仍在規劃中。**

## 下載與使用

請在 GitHub 右側 Releases 下載最新版 Portable（免安裝）或 Setup（安裝版）EXE。使用者不需安裝 Node.js；登入自己的 ChatGPT 帳號，不包含作者帳號或資料。用量顯示另需本機已登入的官方 Codex CLI。EXE 尚未數位簽章。

排程分析及虛擬交易需工具持續執行，關機或睡眠時不執行。第一次使用不回填舊交易。原始碼不含個人資料；使用資料保存在本機。

## 檔案分工

v0.3.3 帳號狀態：選單是「已儲存帳號」，不代表當前仍有有效登入。未連線時顯示「已儲存帳號・分析待登入」，按「重新登入 ChatGPT」才啟用分析；成功授權後顯示「AI 分析已連線」。Codex 用量另顯示自己的連線狀態。側欄文字及字級已精簡，雙週期與點數在 600px 以上的測試視窗可完整呈現；僅改前端，重新整理即可查看。

v0.3.2 介面：帳號資訊與用量集中於貼齊畫面左緣的全高側欄，主標題與內容在右側。預設展開，按三條線圖示可收合／展開，Escape 可關閉，查詢輸入不會因收合清空。重新整理預設展開；手機版為覆蓋式抽屜，可點遮罩關閉。此版僅調整前端，既有 server 開啟時重新整理網頁即可查看。

- `src/`：React 介面。
- `server/`：Node.js API、資料保存、策略；`auth.ts` 管理登入，`ai.ts` 管理模型與串流，`jobs.ts` 管理工作，`usage.ts` 唯讀查詢官方帳號用量。
- `shared/`：前後端共用型別。
- `doc/`：完整規劃、資料契約、開發驗收與版本紀錄。
- `data/database.json`：你的既有資料；`data/codex/database.json`：Codex 預覽資料，皆排除於 Git。

## 啟動方式（須先取得使用者執行同意）

需要 Node.js 22.18 以上；已在本機 Node.js 24.18.0 驗證型別檢查、測試、建置與 HTTP 流程。

```powershell
npm install
npm run check
npm test
npm run build
npm start
```

開啟 http://127.0.0.1:3100 即可查看你的網頁；關閉終端服務後需再次執行 `npm start`。僅監聽本機，不對區域網路開放。已保留 package-lock.json 固定版本。npm 的 esbuild 安裝腳本提示未妨礙本次實際建置；未額外核准腳本。

## 你的版本與 Codex 預覽分開

v0.2.2 起可在啟動服務後，直接雙擊 `dist/index.html`，自動導向 http://127.0.0.1:3100/ ；雙擊 `dist-codex/index.html` 則導向 3101。此功能由 Vite 建置時產生 `file-launcher.js`，重新建置不會遺失。請保留整個 dist 資料夾，不能只複製 index.html。HTML 無法自行啟動 Node.js；仍須先執行 npm start。透過 HTTP 開啟時不重新導向，保留登入回傳的網址參數。

| 用途 | 啟動指令 | 網址 | 資料檔 | 網頁建置目錄 |
|---|---|---|---|---|
| 你專用 | `npm start` | http://127.0.0.1:3100 | `data/database.json` | `dist/` |
| Codex 預覽 | `npm run start:codex` | http://127.0.0.1:3101 | `data/codex/database.json` | `dist-codex/` |

你的 PowerShell：

```powershell
cd "D:\股票\美日分析"
npm start
```

Codex 日後一律使用 `npm run build:codex` 及 `npm run start:codex` 預覽，不占用你的 3100，也不改寫你的 dist 或 data/database.json。你要更新專用網頁時，執行 `npm run build` 後重啟你的服務即可；後端程式有更新也需要重啟。兩套共用原始碼，並非兩份獨立程式版本，但建置檔、程序、登入與資料分開。預覽資料不會自動複製到你的資料庫。

開發熱更新使用 `npm run dev`：前端 http://127.0.0.1:5174 ，代理到 Codex 後端 3101，仍使用預覽資料；不要與 `start:codex` 同時啟動以免 3101 衝突。一般使用無須設定環境變數；`PORT` 和 `DATA_DIR` 只供自訂／測試覆寫，若手動指定相同 DATA_DIR，便不再保有資料隔離，請勿用於兩個同時執行的服務。

登入回傳自動使用當前服務的接埠，兩個版本需要各自登入。排程也分開；若兩邊都登入並啟用排程，可能各消耗一次額度。Codex 預覽預設不登入、不啟用排程。同一接埠仍不能重複啟動，程式會顯示清楚提示，不再輸出未處理例外堆疊。

## 登入、手動查詢與排程

### 直接查看帳號用量

登入或還原本機分析帳號後自動顯示用量，也可按「更新」，即可看到來源帳號、方案、各實際回傳週期的已用／剩餘比例、重置時間、可用點數及最後查詢時間，不再跳到外部用量網頁。啟用後每分鐘更新，一分鐘內的重複更新共用快取。未登入時不自動啟動 CLI；登入成功或服務重啟還原登入後會自動讀取。

用量來源與參考 App 相同：本機官方 Codex CLI 的 App Server，僅呼叫 initialize、account/read 與 account/rateLimits/read，不發送 AI 對話、不變更額度或使用重置點數、不讀取 AiUsage 的帳號資料。本機 Codex 須已以 ChatGPT 帳號登入；這與本工具的分析登入是兩條獨立連線。卡片會列出來源帳號，若與分析帳號不同會顯示提示。Codex 用量不代表 ChatGPT 全部功能或此工具獨立的應用上限；目前只查看，不修改官方限額。沒有提供的週期或數值會顯示未提供，不推估成 100%。查詢失敗會清除後端舊快取，顯示原因。

工具會先從 PATH 尋找官方 Codex CLI；Windows 另支援官方桌面版的 `%LOCALAPPDATA%\OpenAI\Codex\bin` 安裝位置。其他位置可用 CODEX_EXECUTABLE 指定官方 CLI 的絕對路徑。實際驗證 CLI 為 0.162.0-alpha.17.2，已讀到 300 分鐘及 10080 分鐘週期；未假設所有方案都會回傳這兩種週期。

更新至 v0.3.0 後，請在你自己的 PowerShell 按 Ctrl+C，再 npm start，重新整理網頁以載入新 API；不需要重裝套件。v0.3.6 起後端重啟會從本機加密憑證恢復分析帳號，升級後需重新登入一次。Codex 預覽仍使用 3101，不停止你的 3100。

### AI 查詢操作

1. 開啟 http://127.0.0.1:3100 ，點選 **Continue with ChatGPT**，由你在 OpenAI 官方網站完成登入授權。
2. 回到工具，確認額度授權狀態，從帳號實際回傳的清單選模型。
3. 輸入問題，選擇網路查詢或附上最新收盤研究，點選「立即手動查詢」。沒有啟用網路查詢時，模型無法取得即時行情。
4. 要自動查詢時，勾選「啟用排程」、設定台北時間與週一至週五的日期，按「儲存排程設定」。預設時間 12:00，預設不啟用。
5. 查詢紀錄每 5 秒更新，網路查詢必須有引用來源且完整結束才算成功；支援能力取決於帳號與模型，不能保證每個模型支援網路查詢。

關閉網頁不影響仍開啟的服務；電腦睡眠、關機或服務停止則不會執行。每選定平日最多一次，超過預定時間五分鐘不補跑，留下錯過紀錄。尚無交易所休市日曆，平日排程不等於交易日排程。重新整理及重啟服務會自動恢復登入，必要時自動續期；授權失效需重新登入。憑證透過 Windows DPAPI 加密保存在各實例 data/session.dpapi，僅同一 Windows 使用者可還原；database.json 只保留非密碼的帳號識別及註冊關係。登出會停用排程。若只是換帳號，舊排程不會改用新帳號扣額度，需重新儲存。

登入與查詢需要服務能連線至 OpenAI 官方網域。受限制的執行環境可能阻擋連線，會顯示失敗，不關閉驗證或改用非官方端點。問題及勾選的收盤研究會傳給 OpenAI；既有交易明細不會自動附上。

先依 [資料契約](doc/DATA.md) 匯入合法取得的 JSON 日 K，再選日期研究。沒有預載虛構行情。完整範圍與限制見 [規劃書](doc/PLAN.md)，進度見 [開發階段](doc/ROADMAP.md)，版本見 [變更紀錄](doc/CHANGELOG.md)。

不使用另行計費的 API 金鑰，不購買點數，不串券商下單。ChatGPT 查詢使用帳號授權的方案額度或既有點數，請在 ChatGPT 設定限制用量；不承諾無限使用。AI 網路摘要不是全市場即時行情，也不是已驗證回測。備份時停止服務並複製 data 資料夾，不公開交易紀錄。完整能力及來源見 doc/PLAN.md。


## v0.5.0 自動行情查核

開啟網路查詢後，系統會先自動讀取官方上市與上櫃普通股收盤資料、建立跨產業最多 12 檔初選、抓歷史日 K 計算 MA／KD／MACD／量比，再將資料交給 AI 補查消息及比較；不需手動匯入。盤中另抓最近成交時間與買賣價，來源缺漏、過期或缺對手盤均會顯示。結果中的「回覆完成」僅指 AI 回覆結束，請另看「官方行情與初選查核」的資料完整度。這不是全市場技術掃描或已驗證獲利策略。

本版包含後端變更，請在自己的服務視窗按 Ctrl+C，再於 D:\\股票\\每日分析 執行 npm start，並重新整理。官方資料準備最多 150 秒、AI 最多 180 秒，整體約六分鐘內；快取可減少重複抓取。舊查詢不補填查核或改寫結論。本機登入會嘗試從 Windows 加密保存恢復，授權失效才需重新登入。


## Windows EXE（v0.9.1）

打包指令 npm run package:win，輸出在 release/：TaiwanStockLab-Setup-0.9.1-x64.exe 為安裝版，TaiwanStockLab-Portable-0.9.1-x64.exe 為免安裝版。使用者不需另裝 Node.js；首次開啟會自動啟動本機 server 並開啟獨立桌面視窗，首次登入自己的 ChatGPT 帳號。正式產物是否已完成請看 doc/CHANGELOG.md。

預設 3100，占用改選 3102～3130，不停止其他服務。關閉桌面視窗後右下角圖示仍常駐，雙擊圖示再次開啟；從圖示選單「完全結束」才停止。安裝版可自行勾選登入 Windows 後背景啟動；免安裝版沒有這項設定。電腦睡眠或關機無法執行排程。

資料保存在 %APPDATA%/TaiwanStockLab/data，desktop.log 在上層；更新不覆蓋個人資料。EXE 不包含開發者的帳號、憑證或交易資料，也不會自動搬移此專案 data。此版尚未數位簽章；沒有 GitHub 自動更新，無需付費憑證即可先在本機測試。用量顯示仍依賴使用者已安裝並登入的官方 Codex CLI，未安裝時顯示無法讀取，不影響單獨使用 ChatGPT 分析登入。

升級 v0.8.0 前，請先從右下角圖示選單完全結束舊版，再開啟新版 EXE，避免喚起舊版。ChatGPT 授權及來源連結使用外部瀏覽器，授權完成後喚回桌面視窗。登入票證兩分鐘到期且只能使用一次。桌面停用 Node.js 整合並啟用隔離與沙箱。

v0.8.0：查詢結果直接顯示固定候選分類、排除原因與盤中價量。請重新套用隔日出清範本，既有結果不會重寫；新增分類仍可能零檔，規則尚未經回測驗證。

## 10萬元虛擬交易（v0.9.0）

側欄「虛擬交易」查看假錢、持倉、損益及每日名單。手動查詢套用隔日出清範本並勾選「納入10萬元虛擬交易」，或在自動排程套用範本、選模型、勾選納入並儲存啟用。每日首份結果鎖定，同日不重複買進。公布後須取得新報價且未超過13:20；下一預定交易日13:20起模擬出清。服務必須持續開啟；首次使用不回填舊查詢。

AI分析搭配固定模擬規則，不是自由文字下單；費用、滑價、逐股模擬與日曆限制見頁面，無真實券商或既有回測績效。新EXE驗證通過才清理舊版，升級前先從右下角完全結束舊程式。

v0.9.1 排程：先檢查官方開休市日曆及當日兩市場指數。休市顯示「休市略過」，來源失敗或無法確認顯示「開休市未確認」，都不發送AI。設定與帳本保留；更新後需完全結束舊版再開新版。盤前無法確認當日實際交易也會略過。
